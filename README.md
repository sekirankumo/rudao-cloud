# 入到云盘

在安卓手机 / 平板上浏览电脑里的 [Eagle](https://eagle.cool) 素材库：瀑布流网格、文件夹、标签筛选、随机浏览，视频边下边播。

> 这是客户端。它需要电脑上运行一个配套的局域网服务（读取 Eagle 库并提供接口），该服务不在本仓库中。

## 功能
- 元数据同步到手机本地，浏览 / 筛选 / 搜索都很快，只有缩略图和播放走网络
- 侧栏：全部 / 收藏 / 标签树（多选、可搜索），Eagle 文件夹可在菜单里开启
- 本机收藏：只存在这台手机上，不会写回电脑
- 随机浏览、换一批；随机速览：自动连播随机视频的随机片段
- 缩略图大小无级调节（滑块或双指缩放）
- 播放器：上下滑切换，左右拖动调进度，双击暂停 / 继续，长按二倍速，倍速
- 顶部指示灯显示能否连上服务器
- 从 GitHub Releases 检查并安装更新

## 构建
Android Studio 打开本目录即可；或命令行：

```bash
./gradlew assembleDebug
```

## 发布新版本
推送 `v*` 标签后，GitHub Actions 会编译、签名并发布到 Releases（见 `.github/workflows/release.yml`），已安装的 App 会提示更新。
